# Laboratorio — cierre previo a la segunda campaña

Esta carpeta reúne el método, el registro del piloto, el protocolo congelado y las plantillas para documentar la segunda campaña de AURA.

## Contenido

- `00_METODOLOGIA.md`: qué evalúa AURA y cómo calcula cada métrica.
- `01_CAMPANA_PILOTO.md`: qué aprendimos de la campaña piloto y por qué no se presenta como resultado definitivo.
- `02_PROTOCOLO_SEGUNDA_CAMPANA.md`: condiciones que no deben cambiar durante las 27 corridas.
- `03_RESULTADOS_SEGUNDA_CAMPANA.md`: plantilla para consignar únicamente resultados reales exportados por AURA.
- `04_TEXTO_PARA_TFM.md`: texto base listo para integrar en el documento académico.
- `screenshots/`: evidencia visual del flujo y de la presentación de resultados.

## Advertencia sobre las capturas

Las capturas actuales se generaron con un recorrido E2E determinista para verificar diseño, navegación, selección de configuración y exportación. No representan resultados reales ni deben usarse para afirmar que un modelo superó a otro. Las cifras definitivas deben sustituirse con la exportación de la segunda campaña real.

## Criterio de cierre

La campaña se considera utilizable cuando las 27 unidades fueron intentadas, los fallos permanecen visibles, el reporte supera sus validaciones internas y el expediente exportado contiene los nueve artefactos con sus hashes.
