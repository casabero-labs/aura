## Objective
Cerrar el riesgo aceptado en L9: L9 validó el contrato de exportación usando harness (CSV no cargado desde UI). L10 recorre el flujo visible completo desde carga CSV sintético hasta exportación técnica 2.0, usando provider mock y sin depender de modelos reales.

## Harness Strategy

### What is mocked (harness)
- AI diagnosis: `__PHASE4_INJECT__` injects minimal `DiagnosisExecutionResult`
- Pipeline state: `__PHASE3_SET_STATE__` jumps through `diagnosis → review → export`
- Audit report: `__L9_SET_REPORT__` sets `AuditReport` with correct row/col counts

### What is NOT mocked (real UI flow)
- CSV file selection via `page.setInputFiles()` on the real hidden file input
- CSV parsing: `parseCsv()` runs in-browser on the real File object
- Audit engine: `runAudit()` runs deterministically in-browser
- State transitions: driven by React `setState` via harness callbacks

### Point of harness entry
```
boot → load CSV (real UI) → profile state → __PHASE4_INJECT__ (diagnosis)
→ __PHASE3_SET_STATE__('diagnosis') → __PHASE3_SET_STATE__('review')
→ __PHASE3_SET_STATE__('export') → __L9_GET_EXPORT_JSON__(FAKE_REPORT)
```

Harness bypasses: real AI diagnosis, real calibration benchmark, real script generation.
Harness does NOT bypass: CSV loading, CSV parsing, deterministic audit run.

## Constraints Respected

- No real data — all fixture data synthetic
- No model download — harness bypasses AI provider
- No real AI provider — `providerMode: mock`
- No changes to `auditEngine`, scoring, v2 contracts, Phase 5-9 freezes
- No touches to `docs/tercera_entrega_aura/`
- No production-ready, benchmark definitivo, mejor modelo universal, or fourth delivery claims

## Risks

- Harness state-jumping (`__PHASE3_SET_STATE__`) bypasses some UI rendering that would occur in a real flow
- The export JSON is derived from `buildAuraExportPackage` with harness-injected data, not a full real pipeline run
- Profile/report counts reflect the harness-injected `FAKE_REPORT`, not the actual parsed CSV audit result (they are matched in this test by design)
