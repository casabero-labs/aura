Conecta Ollama
sin pelearte con la terminal.

AURA detectará tu sistema operativo y te mostrará solamente los pasos necesarios. La conexión se realiza desde este navegador hacia Ollama en tu equipo.

🔒
Ruta privada: navegador → Ollama local El dataset, el prompt y la respuesta no pasan por el servidor de AURA cuando usas Ollama.
1

Confirmar tu equipo

Ajustaremos las instrucciones a tu sistema y navegador.

Detectando…

Descargar Ollama
2

Autorizar a AURA

Ollama debe aceptar peticiones desde este dominio.

No uses OLLAMA_ORIGINS=*. AURA genera el origen exacto para mantener la configuración cerrada.
3

Instalar un modelo

Recomendamos un modelo pequeño para la primera validación.

Recomendado: Qwen 2.5 3B. Buen equilibrio entre español, velocidad y consumo.

ollama pull qwen2.5:3b

Equipo con poca memoria:

ollama pull gemma2:2b
4

Solicitar permiso y conectar

El navegador comprobará Ollama directamente en este equipo.

Chrome o Edge pueden mostrar un permiso para que se conecte a servicios locales. Pulsa Permitir.

Si usas Chrome o Edge, es posible que el navegador bloquee el acceso a la red local sin tu permiso explícito:
  1. Haz clic en el icono de candado o en los controles del sitio (izquierda de la barra de direcciones).
  2. Selecciona Configuración del sitio o Permisos del sitio.
  3. Busca Acceso a la red local y selecciona Permitir.
  4. Recarga esta página y vuelve a intentar.
